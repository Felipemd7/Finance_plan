Configurações

📋 Como Funciona

  1. Durante a sessão: Seus dados ficam na memória do navegador e funcionam normalmente
  2. Ao fechar o navegador: Os dados são perdidos (limitação do ambiente)
  3. Solução: Clique em "Fazer Backup" para baixar seus dados em JSON
  4. Para restaurar: Use "Restaurar Backup" e selecione o arquivo JSON salvo
  5. Backup automático: Ative para baixar backup automaticamente após cada importação de Excel
